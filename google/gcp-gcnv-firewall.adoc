= 防火牆
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Google Cloud NetApp Volumes公開多個 TCP 連接埠來為 NFS 和 SMB 共用提供服務：

* https://docs.cloud.google.com/netapp/volumes/docs/connect-clients/connect-nfs-clients#firewall_rules_for_nfs_volumes_access["NFS 存取所需的連接埠"^]
* https://docs.cloud.google.com/netapp/volumes/docs/connect-clients/connect-smb-clients#firewall_rules_for_smb_volumes_access["SMB 存取所需的連接埠"^]


此外，SMB、包含 Kerberos 的 LDAP 的 NFS 以及雙協定組態需要存取 Windows Active Directory 網域。Active Directory 連線必須 https://docs.cloud.google.com/netapp/volumes/docs/configure-and-use/active-directory/create-ad-policy["配置"^]以每個區域為基礎。Active Directory 網域控制站（DC）是使用 https://docs.microsoft.com/en-us/openspecs/windows_protocols/ms-adts/7fcdce70-5205-44d6-9c3a-260e616a2f04["基於 DNS 的 DC 發現"^]透過指定的 DNS 伺服器來識別。系統會使用傳回的任何 DC。可以透過指定 Active Directory 站台來限制符合條件的 DC 清單。

Google Cloud NetApp Volumes 使用透過 `gcloud compute address`命令指派的 CIDR 範圍內的 IP 位址進行通訊 https://docs.cloud.google.com/netapp/volumes/docs/plan-and-prepare/networking#configure_private_services_access["加入Google Cloud NetApp Volumes"^]。您可以將此 CIDR 用作來源位址，為 Active Directory 網域控制站設定傳入防火牆。

Active Directory 網域控制站必須 https://docs.cloud.google.com/netapp/volumes/docs/plan-and-prepare/security-considerations["如這裡所述，將連接埠暴露給Google Cloud NetApp Volumes CIDR"^]。
